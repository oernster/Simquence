Questions

What is a design-time latency simulator?

A tool that predicts how long a flow takes from a model of its design rather than from running code. Simquence runs a model of tasks, events and shared resources thousands of times and reports latency percentiles from p50 to p99 with the critical path of each run.

How is it different from a profiler or APM tool?

A profiler or APM tool measures a system that already runs. Simquence works on the design before the code exists, so a structural decision can be tested while it is still cheap to change.

What can it model?

Any event-driven software: a web checkout, a desktop UI thread, a microservice fan-out, a mobile flow or an embedded pipeline. Queueing comes from each context's concurrency; debounces, backoffs and poll intervals are delays on the wiring.

Are the results reproducible?

Yes. Every run is seeded, so the same model and seed give the same answer every time. Rerun a changed model on the same seed and any difference is the design change rather than luck.

Is it free? Does it send my models anywhere?

It is free under GPL-3.0, with an LGPL-3.0 desktop interface. Models and results stay on your machine; the only outbound call is an anonymous daily check of GitHub for a newer release.
